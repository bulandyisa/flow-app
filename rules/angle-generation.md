# Правила генерации ракурсов (КРИТИЧНО для консистентности)

## Главный принцип
Базовый принятый образ локации/персонажа — ЕДИНСТВЕННЫЙ источник правды.
Каждый ракурс должен выглядеть так, как будто камера просто переместилась,
а не как будто это другая локация.

## Для локаций

### Ингредиенты
- Image 1: ВСЕГДА принятый базовый образ локации (base.png)
- Других ингредиентов НЕТ (только базовый образ)

### Промпт для каждого ракурса
```
Reproduce the EXACT same location from Image 1 — same walls, same floor,
same furniture, same objects, same colors, same textures, same lighting.
NOTHING added, NOTHING removed, NOTHING changed.

Camera angle: [описание ракурса]

The location must be IDENTICAL to Image 1 in every detail.
Only the camera position and angle change.

No text, no watermarks. 3D Pixar-style, family-friendly, cinematic.
```

### Критичные правила консистентности
1. **Все объекты на месте** — если на столе стоит ваза в базовом образе, она стоит в КАЖДОМ ракурсе
2. **Цвета идентичны** — стены, пол, мебель — тот же оттенок
3. **Текстуры идентичны** — деревянный пол остаётся деревянным, не становится плиточным
4. **Освещение одинаковое** — направление света, тени, яркость
5. **Масштаб объектов** — стол не становится больше/меньше при смене ракурса
6. **Архитектура** — двери, окна, стены в тех же позициях
7. **Мелкие детали** — картины на стенах, ручки дверей, выключатели — всё сохраняется

### Запрещено в промптах ракурсов
- НЕ описывать интерьер/экстерьер — модель берёт из базового образа
- НЕ добавлять новые объекты ("with a vase of flowers" — только если есть в базовом)
- НЕ менять время суток (если в базовом день — везде день)
- НЕ менять погоду (если солнечно — везде солнечно)
- НЕ использовать слова: "similar", "like", "inspired by" — только "EXACT same", "IDENTICAL"

## Для персонажей

### Ингредиенты
- Image 1: ВСЕГДА принятый базовый образ персонажа (base.png)

### Промпт для каждого ракурса
```
The EXACT same character from Image 1 — same face, same body proportions,
same clothing, same hairstyle, same accessories. IDENTICAL appearance.

Pose: [описание позы/ракурса]

No text, no watermarks. 3D Pixar-style, family-friendly, cinematic.
```

### Критичные правила
1. **Лицо идентично** — те же черты, тот же возраст
2. **Одежда идентична** — тот же цвет, тот же стиль, те же детали
3. **Пропорции тела** — рост, телосложение не меняются
4. **Аксессуары** — очки, шапки, украшения — всё на месте

## Типы ракурсов для локаций (минимум 15)

### Широкие планы (4-5 ракурсов)
- wide_front: Фронтальный общий план
- wide_left: Общий план слева (30-45°)
- wide_right: Общий план справа (30-45°)
- wide_back: Общий план сзади (если применимо)
- establishing: Устанавливающий кадр (самый широкий)

### Средние планы (4-5 ракурсов)
- medium_from_door: От двери/входа
- medium_from_window: От окна
- medium_from_corner: Из угла комнаты
- medium_center: Из центра помещения
- medium_elevated: Слегка сверху (верхний ракурс)

### Крупные планы деталей (4-5 ракурсов)
- closeup_detail_1: Ключевая деталь (стол, верстак, кровать)
- closeup_detail_2: Вторая деталь (полка, окно, дверь)
- closeup_detail_3: Третья деталь (предметы на столе, книги)
- closeup_floor: Пол/ступени крупным планом
- closeup_wall: Стена с деталями крупным планом

### Специальные ракурсы (2-3)
- pov_inside_out: Изнутри наружу (через дверь/окно)
- pov_outside_in: Снаружи внутрь
- low_angle: Снизу вверх
- high_angle: Сверху вниз
