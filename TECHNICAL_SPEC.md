# Техническое задание: Flow Video Automation Tool
# Автоматизация генерации мультфильма «Лучи истины» в Google Flow (VEO 3.1)

## 1. ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА

### Цель
Создать Python-приложение, которое автоматизирует полный цикл генерации видео для анимационного сериала:
Сценарий → Разбивка на сцены → Генерация промптов → Автоматическая отправка в Google Flow → Скачивание готовых клипов

### Мультсериал
- **Название:** «Лучи истины» (Rays of Truth)
- **Стиль:** 3D Pixar-style анимация
- **Целевая аудитория:** дети (но не YouTube Kids)
- **Языки:** русский (основной), английский, индонезийский, испанский
- **Контекст:** мусульманская семья, исламский контекст как естественный фон

### Текущий workflow (ручной)
1. Сценарист пишет сценарий
2. Монтажёр читает сценарий и вручную составляет промпты для VEO 3
3. Монтажёр заходит в Flow, выбирает режим, загружает референсы, вставляет промпт
4. Ждёт генерацию, оценивает результат, перегенерирует если нужно
5. Скачивает удачные клипы, склеивает в монтажной программе

### Целевой workflow (автоматизированный)
1. Пользователь загружает сценарий в инструмент
2. Инструмент разбивает на сцены, генерирует промпты, подбирает референсы
3. Пользователь просматривает и корректирует (ревью-интерфейс)
4. Бот автоматически отправляет всё в Flow и скачивает результаты
5. Готовые клипы в папке, подписанные номерами сцен

## 2. АРХИТЕКТУРА

### Модули

#### Модуль 1: Парсер сценария
- Вход: текст сценария (вставлен или файл .txt/.docx)
- Разбивает на сцены
- Для каждой сцены определяет:
  - Какие персонажи участвуют (по именам из справочника)
  - Какая локация (по названиям из справочника)
  - Какое действие происходит
  - Есть ли диалоги
  - Настроение сцены
- Выход: структурированный JSON со сценами

#### Модуль 2: Генератор промптов
- Вход: JSON со сценами + справочники персонажей и локаций
- Для каждой сцены генерирует промпт по формуле Google:
  [Cinematography] + [Subject] + [Action] + [Context] + [Style & Ambiance]
- Промпты на АНГЛИЙСКОМ языке (VEO лучше работает с английскими промптами)
- Определяет режим генерации:
  - Ingredients to Video — если нужны 2-3 референса (персонаж + локация)
  - Frames to Video (First Frame) — если есть готовый начальный кадр
  - Text to Video — если сцена общая без конкретных персонажей
- Подбирает файлы референсов из справочника
- Выход: JSON с промптами и метаданными для каждой сцены

#### Модуль 3: Ревью-интерфейс (CLI или веб)
- Показывает таблицу: номер сцены → промпт → режим → референсы
- Позволяет редактировать промпт
- Кнопка «Запустить генерацию» / «Экспортировать промпты»
- Кнопка «Скопировать промпт» для ручного режима

#### Модуль 4: Бот-генератор (Playwright)
- Открывает Google Flow в Chromium
- Для каждой сцены выполняет:
  1. Выбирает режим «Видео по образцам» (Ingredients to Video)
  2. Нажимает «+» для добавления ингредиента
  3. Нажимает «Загрузить» — открывается файловый диалог ОС
  4. Перехватывает файловый диалог и указывает путь к файлу референса
  5. На экране кадрирования нажимает «Кадрировать и сохранить» (без изменений)
  6. Повторяет для дополнительных ингредиентов (до 3)
  7. Вставляет промпт в текстовое поле
  8. Убеждается что выбрана модель: Veo 3.1 - Fast [Lower Priority] (0 кредитов)
  9. Нажимает кнопку Generate (стрелка →)
  10. Ждёт завершения генерации
  11. Переходит к следующей сцене
- Обработка ошибок: если генерация не удалась, логирует и пропускает
- Rate limiting: пауза между генерациями (Flow ограничивает частоту для zero-credit моделей)

#### Модуль 5: Сборщик результатов
- Скачивает сгенерированные клипы из Flow
- Именует: scene_001_amin_kitchen.mp4, scene_002_tako_street.mp4
- Создаёт отчёт: какие сцены готовы, какие нужно перегенерировать

## 5. НАСТРОЙКИ FLOW

### Модель
- **Veo 3.1 - Fast [Lower Priority]** — 0 кредитов за генерацию (бесплатная)
- Подписка: Ultra

### Параметры генерации
- Соотношение сторон: горизонтальное (16:9) по умолчанию  
- Результатов на запрос: 4 (x4)
- Аудио: включено (иконка звука активна)

### Режимы работы
- **Видео по образцам** (Ingredients to Video) — основной режим, до 3 изображений-ингредиентов
- **Видео по кадрам** (Frames to Video) — если нужен конкретный начальный/конечный кадр

### Процесс загрузки изображения в Flow
1. Нажимается кнопка «+» в промпт-баре
2. Открывается библиотека изображений проекта + кнопка «Загрузить»
3. При нажатии «Загрузить» — стандартный файловый диалог ОС (macOS Finder)
4. После выбора файла — экран «Кадрирование образца» 
5. Нажимается «Кадрировать и сохранить» (без изменения кадрирования)
6. Изображение автоматически появляется в промпт-баре как ингредиент
7. Для добавления следующего — снова «+»

### URL
- Flow: https://labs.google/flow
- Проект «Nadi» уже создан

### Ограничения
- Flow rate-limits zero-credit генерации: после большого количества генераций за день скорость снижается
- Бот должен делать паузы между генерациями (рекомендуется 30-60 сек)
- Иногда аудио не генерируется — это нормально, кредиты возвращаются

## 8. ПРИМЕЧАНИЯ

### Формат промптов VEO 3.1 (формула Google)
[Cinematography] + [Subject] + [Action] + [Context] + [Style & Ambiance]

Пример:
"Medium shot, a 7-year-old chubby boy with curly brown hair and a burgundy backwards cap, running excitedly through a warm beige-pistachio kitchen, grabbing a piece of bread from the table while his mother in black hijab turns around in surprise. Warm afternoon light from the arched window, cozy family atmosphere, 3D Pixar-style animation."

### Timestamp prompting (для сложных сцен)
[00:00-00:02] Close-up of Tako's face, eyes widening with excitement...
[00:02-00:04] Medium shot, Tako grabs bread and runs...
[00:04-00:08] Wide shot, mother turns around, calling after him...

### Важно помнить
- VEO 3.1 генерирует клипы по 4, 6 или 8 секунд
- Для 10-минутного видео нужно ~75-150 клипов
- Ingredients to Video поддерживает до 3 референсных изображений
- Речь в промпте указывается в кавычках: says "text here"
- Речь на несовершеннолетних отключена моделью (актуально для детских персонажей!)
