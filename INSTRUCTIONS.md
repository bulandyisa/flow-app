# Пошаговая инструкция: запуск проекта в Claude Code

## Шаг 1: Установка Claude Code (если ещё не установлен)

Claude Code — это терминальное приложение. Открываете Terminal (на Mac: Cmd+Space → "Terminal").

Вводите:
```
npm install -g @anthropic-ai/claude-code
```

Для этого нужен Node.js. Если у вас его нет:
- Зайдите на https://nodejs.org
- Скачайте LTS версию
- Установите
- После установки перезапустите Terminal
- Потом `npm install -g @anthropic-ai/claude-code`

После установки вам нужно авторизоваться:
```
claude
```
При первом запуске он попросит API ключ Anthropic или войти через аккаунт.
Если у вас подписка Claude Pro/Max — можно использовать через неё.


## Шаг 2: Подготовка папки проекта

1. Скачайте все файлы из нашего чата (кнопка скачивания в outputs):
   - TECHNICAL_SPEC.md
   - character_reference.csv
   - location_reference.csv
   - scenario_signal.txt
   - Папка «персонажи» (15 фото)
   - Папка «локации» (14 фото)

2. Создайте на компьютере папку проекта. Например:
```
mkdir ~/flow-automation
mkdir ~/flow-automation/refs
mkdir ~/flow-automation/refs/персонажи
mkdir ~/flow-automation/refs/локации
```

3. Переместите скачанные файлы:
   - TECHNICAL_SPEC.md → ~/flow-automation/refs/
   - character_reference.csv → ~/flow-automation/refs/
   - location_reference.csv → ~/flow-automation/refs/
   - scenario_signal.txt → ~/flow-automation/refs/
   - Все фото персонажей → ~/flow-automation/refs/персонажи/
   - Все фото локаций → ~/flow-automation/refs/локации/

4. Проверьте что всё на месте:
```
ls ~/flow-automation/refs/
```
Должно показать:
```
TECHNICAL_SPEC.md
character_reference.csv
location_reference.csv
scenario_signal.txt
персонажи/
локации/
```


## Шаг 3: Запуск Claude Code

1. В Terminal перейдите в папку проекта:
```
cd ~/flow-automation
```

2. Запустите Claude Code:
```
claude
```

3. Claude Code откроется — вы увидите строку ввода в терминале.


## Шаг 4: Первая команда — чтение ТЗ

Скопируйте и вставьте это сообщение:

```
Прочитай файл refs/TECHNICAL_SPEC.md — это техническое задание на проект автоматизации генерации видео. 

Также прочитай:
- refs/character_reference.csv — справочник персонажей с файлами изображений
- refs/location_reference.csv — справочник локаций с файлами изображений
- refs/scenario_signal.txt — тестовый сценарий эпизода «Сигнал»

Изображения персонажей лежат в refs/персонажи/, изображения локаций — в refs/локации/.

Реализуй Этап 1 из ТЗ:
1. Парсер сценария (parse_scenario.py) — разбивает сценарий на сцены, определяет персонажей, локации, действия, диалоги
2. Генератор промптов (generate_prompts.py) — создаёт VEO 3.1 промпты по формуле Google, подбирает режим генерации и референсные файлы
3. Ревью-интерфейс (review.py) — показывает таблицу промптов, позволяет копировать

Для теста: распарси scenario_signal.txt и сгенерируй промпты только для гаражных сцен (сцены 1, 2, 4, 5). Персонажи в этих сценах: Амин, Карим, Тако. Локация: гараж.

Важно:
- Промпты должны быть на АНГЛИЙСКОМ языке
- Формат промпта: [Cinematography] + [Subject] + [Action] + [Context] + [Style & Ambiance]
- Каждая сцена может содержать несколько клипов по 6-8 секунд
- Режим генерации: Ingredients to Video (если есть референсы), Text to Video (если нет)
- Максимум 3 ингредиента на клип (ограничение Flow)
- VEO не генерирует речь несовершеннолетних — помечай это в метаданных
- Стиль: 3D Pixar-style animation
```

Claude Code прочитает все файлы и начнёт писать код.


## Шаг 5: Что будет происходить

Claude Code будет:
1. Читать ваши файлы
2. Создавать Python-скрипты
3. Устанавливать зависимости (pip install ...)
4. Запускать скрипты и показывать результат
5. Спрашивать разрешение перед каждым действием (нажимайте Y/Enter для подтверждения)

Если Claude Code спросит «Can I run this command?» или подобное — читайте что он хочет сделать и подтверждайте.


## Шаг 6: Проверка результата

После завершения у вас должны появиться:
- scripts/parse_scenario.py
- scripts/generate_prompts.py
- scripts/review.py
- output/prompts/ — JSON файлы с промптами для гаражных сцен

Промпты должны выглядеть примерно так:
```json
{
  "scene_id": "S02",
  "clip_id": "S02_A",
  "prompt": "Wide shot of a garage interior, daytime light...",
  "mode": "ingredients_to_video",
  "ingredients": ["char_amin_full.png", "loc_garazh_inside.jpg"],
  "duration": 8,
  "audio_note": "..."
}
```


## Шаг 7: Если что-то пошло не так

- Если Claude Code выдал ошибку — просто напишите: «Исправь эту ошибку»
- Если результат не нравится — опишите что не так: «Промпты слишком короткие, добавь больше деталей из описания персонажей»
- Если хотите изменить подход — скажите прямо: «Сделай по-другому: ...»
- Можно всегда написать: «Покажи мне сгенерированные промпты для сцены 2»


## Шаг 8: После успешного теста

Если гаражные сцены получились хорошо, следующие шаги:
1. Скажите: «Теперь сгенерируй промпты для ВСЕХ сцен сценария»
2. Проверьте результат
3. Скопируйте лучшие промпты и протестируйте вручную в Flow
4. Если промпты дают хорошие видео — переходим к Этапу 2 (Playwright бот)


## Полезные команды в Claude Code

- `/help` — справка
- `/clear` — очистить контекст
- Ctrl+C — прервать текущее действие
- Просто пишите на русском — Claude Code понимает

## Примечание

Claude Code работает в вашем терминале и имеет доступ к файловой системе. Он создаёт файлы прямо в папке проекта. Все изменения видны в Finder/проводнике. Вы в любой момент можете открыть созданные файлы в текстовом редакторе и посмотреть что внутри.
